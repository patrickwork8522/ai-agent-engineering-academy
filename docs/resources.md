# Start here: trusted learning resources

Use these official pages as starting points. APIs, prices and project architectures change; confirm documentation when doing a real build.

## Guided agent learning

- [Hugging Face Agents Course](https://huggingface.co/learn/agents-course/en/unit0/introduction) — fundamentals, framework exercises, structured learning and associated video/live-session material.
- [Hugging Face Unit 1](https://huggingface.co/learn/agents-course/en/unit1/introduction) — agent definitions, tools and actions.

## Platforms and workflows

- [n8n documentation](https://docs.n8n.io/) — visual automation and AI workflow examples.
- [Dify documentation](https://docs.dify.ai/) — visual AI application and knowledge workflows.
- [Microsoft Copilot Studio documentation](https://learn.microsoft.com/en-us/microsoft-copilot-studio/) — enterprise agent authoring.
- [Make documentation](https://www.make.com/en/help) — scenario automation.

## Coding and system design

- [Python tutorial](https://docs.python.org/3/tutorial/) — refresh programming fundamentals.
- [OpenAI API docs](https://platform.openai.com/docs) — one example of a model API and tool interfaces.
- [LangGraph Python learning](https://docs.langchain.com/oss/python/learn) — stateful orchestration and persistence.
- [FastAPI tutorial](https://fastapi.tiangolo.com/tutorial/) — HTTP interfaces.
- [Docker getting started](https://docs.docker.com/get-started/) — packaging and deployment.
- [Model Context Protocol](https://modelcontextprotocol.io/introduction) — standardized tool/data connections.

## Real-world repository investigations

Start with one of the six project links in the academy's Case Studies section. For each, inspect its README, examples, actual code entry point and documented security model. Write a short note answering: *what problem is solved, what is deterministic, what is model-driven, what can fail, and what would using this cost?*
